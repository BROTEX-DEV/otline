# 🌍 جنگ جهانی آتلاین | Atlain World War

نسخه بلهٔ بازی متنی «جنگ جهانی آتلاین» با Python و کتابخانه `python-bale-bot`.

## امکانات
- ساخت خودکار کشور برای هر بازیکن
- نمایش آمار کشور
- طلا و نیرو
- جذب نیرو با طلا
- توسعه سطح کشور
- مأموریت‌های داستانی با نتیجه تصادفی
- ذخیره اطلاعات بازیکنان در SQLite

## اجرا در Termux

1. وارد پوشه پروژه شو:
   ```bash
   cd otline
   ```

2. کتابخانه‌ها را نصب کن:
   ```bash
   pip install -r requirements.txt
   ```

3. توکن رباتی را که از BotFather در پیام‌رسان بله گرفته‌ای تنظیم کن. توکن را در GitHub یا چت عمومی منتشر نکن:
   ```bash
   export BALE_BOT_TOKEN="توکن_ربات_بله"
   ```

4. ربات را اجرا کن:
   ```bash
   python main.py
   ```

5. در بله وارد ربات شو و دستور `/start` را بفرست.

## دستورهای بازی
- `/start` — شروع بازی
- `/help` — راهنما
- `/country` — نمایش کشور
- `/stats` — آمار کشور
- `/recruit` — جذب ۱۰ نیرو با هزینه ۱۰۰ طلا
- `/upgrade` — ارتقای کشور
- `/mission` — مأموریت داستانی

## امنیت
- توکن ربات را در کد، GitHub یا پیام عمومی قرار نده.
- اگر توکن منتشر شد، از BotFather آن را باطل و توکن تازه بگیر.
- فایل `atlain_bale.db` اطلاعات بازی را نگه می‌دارد؛ حذف آن باعث از دست رفتن پیشرفت بازیکنان می‌شود.

## اجرای دائمی
تا وقتی برنامه در Termux اجراست، ربات پاسخ می‌دهد. GitHub به‌تنهایی ربات را ۲۴ساعته اجرا نمی‌کند.

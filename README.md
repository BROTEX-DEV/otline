# 🌍 جنگ جهانی آتلاین | Atlain World War

یک بازی متنی تلگرام با Python و کتابخانه `python-telegram-bot`.

## امکانات نسخه اولیه
- ساخت خودکار کشور برای هر بازیکن
- نمایش آمار کشور
- طلا و نیرو
- جذب نیرو با طلا
- توسعه سطح کشور
- مأموریت‌های داستانی با نتیجه تصادفی
- ذخیره اطلاعات در SQLite

## اجرا روی گوشی با Termux یا روی کامپیوتر

1. نصب Python 3.10 یا جدیدتر
2. نصب وابستگی‌ها:

   ```bash
   pip install -r requirements.txt
   ```

3. توکن را به‌صورت متغیر محیطی تنظیم کن. توکن را در کد یا مخزن عمومی قرار نده.

   **Termux / Linux:**
   ```bash
   export BOT_TOKEN="توکن_ربات"
   python main.py
   ```

   **Windows PowerShell:**
   ```powershell
   $env:BOT_TOKEN="توکن_ربات"
   python main.py
   ```

4. در تلگرام به ربات برو و `/start` را بفرست.

## امنیت توکن
- توکن ربات را در GitHub، فایل README یا پیام عمومی منتشر نکن.
- اگر توکن جایی منتشر شد، از BotFather آن را عوض کن.

## ذخیره‌سازی
اطلاعات بازیکنان در فایل `atlain.db` ذخیره می‌شود. اگر سرویس میزبانی فایل‌های محلی را پس از راه‌اندازی مجدد پاک کند، باید از پایگاه دادهٔ پایدار استفاده شود.

## وضعیت اجرا
GitHub محل نگهداری کد است و به‌تنهایی ربات را به‌صورت ۲۴ساعته اجرا نمی‌کند. برای آنلاین ماندن دائمی، باید بعداً آن را روی یک سرویس میزبانی مناسب مستقر کنیم.
